# Release checklist

- [ ] Inspect original manual, Explorer source, licenses and actual 2 GB bytes
- [ ] Provenance manifest and safe repeatable reference downloader
- [ ] Validated format, Disk BASIC read/write, OS-9 read/extract
- [ ] Immutable originals, transactional working images and partition management
- [ ] Disk/batch/volume import and export with explicit geometry and mapping
- [ ] Streaming, durable, verified complete backups and restore
- [ ] Real Linux enumeration, protection checks and narrow privileged helper
- [ ] Connected desktop actions, progress, cancellation and review
- [ ] Offline corruption/failure/GUI tests and disposable full-image integration
- [ ] Linux build, launcher, helper installer, documentation and clean git commits
- [ ] Physical spare-card validation (requires separate user authorization)
